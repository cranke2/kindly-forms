# Kindly Forms

Plain-English help for families filling in UK benefit forms for an older parent. The first tool is a free Attendance Allowance checker.

Live site: https://cranke2.github.io/kindly-forms/

- `index.html`: the free checker and the claim helper pre-order
- `guides/`: free how-to guides
- Everything runs in the browser. Nothing a visitor enters is stored or sent anywhere.

Kindly Forms is independent and not linked to the DWP or any government department.
